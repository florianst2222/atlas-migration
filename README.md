# Österreich-Atlas Migration

Ausländeranteil in allen österreichischen Gemeinden und Wiener Bezirken, 2012–2026.
Daten: Statistik Austria (Open Data, CC BY 4.0), umgerechnet auf Gebietsstand 2026.

Dateien:
- `daten.json` – Kennzahlen je Gemeinde
- `gemeinden.topo.json` – vereinfachte Gemeindegrenzen (TopoJSON)
- `atlas.js`, `atlas.css` – Einbettung (`<div id="atlas-migration" data-base="…/">`)
